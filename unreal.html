AUDIO EVENT CONDUCTOR

The Audio Event Conductor, An Unreal Plugin Wwise inspired workflow that takes Built in Unreal Engine Audio to the next level.

ADFX SOUND NODE

Auto populate all the subsequent variations based on Input reference Sound name of the sound variations you want to use.

ADFX FOOTSTEP SYSTEM

Unreal Engine Plugin built in C++ designed to detect and play effects based on Physical Materials. Easy to install and use right away in your project, featuring professionally recorded foley assets tracked at Technicolor on the Paramount Lot in Hollywood.

FOOTSTEP LINE TRACE

This detects Physical Material type, and slope angle beneath the customizable bone (ie, foot l and foot r). Water detection switches from line trace, to sphere trace with Blue DrawDebugSphere. CVAR ShowFootstepDebug 1.
